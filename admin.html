How changes go live

Everything you do here is a private draft, saved only in this browser — the live site is unaffected until you publish it. When you're ready: click Export Product Data. It downloads a file called products-data.json containing your entire catalogue (old and new products together). Upload it to your GitHub repo, replacing the file products-data.json in the root of the repo (no folders — every file sits at the top level) — that single file is what every visitor's Home and Shop pages read from. You're always replacing the whole file, never merging by hand, so there's no risk of duplicating or losing products.
